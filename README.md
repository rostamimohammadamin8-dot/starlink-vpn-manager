# مدیر VPN استارلینک

یک برنامهٔ دسکتاپ ویندوز برای واردکردن و مدیریت تونل‌های WireGuard.

## امکانات

- واردکردن فایل‌های `.conf` و بررسی ساختار پایهٔ WireGuard
- نگهداری پیکربندی‌ها به‌شکل رمزگذاری‌شده با DPAPI و محدود به حساب کاربری فعلی ویندوز
- مشاهدهٔ وضعیت سرویس تونل و اتصال، قطع یا حذف آن
- تازه‌سازی وضعیت تونل‌ها هر ۸ ثانیه و انتخاب مسیر واقعی شبکه برای تشخیص دروازهٔ محلی
- نمایش زمان آخرین handshake و تغییر نرخ دریافت/ارسال peerها در نمونه‌های دوره‌ای (در صورت موجودبودن `wg.exe`)
- درخواست UAC ویندوز برای عملیات نیازمند دسترسی مدیریتی
- آزمایش دستی تأخیر و اتلاف بسته در دروازهٔ محلی و دو مقصد DNS عمومی، به‌همراه پیشنهادهای تشخیصی

این برنامه کلید یا سرور VPN فراهم نمی‌کند. برای اتصال، فایل پیکربندی معتبر از ارائه‌دهندهٔ VPN لازم است. فایل موقتِ رمزگشایی‌شده هنگام نصب سرویس ساخته و پس از پایان عملیات حذف می‌شود؛ فایل پیکربندی رمزگذاری‌شده برای استفاده‌های بعدی در پوشهٔ محلی کاربر می‌ماند. وضعیت «فعال» فقط اجرای سرویس ویندوز را نشان می‌دهد؛ جزئیات handshake و شمارنده‌های ترافیک از زیرفرمان‌های محدود `wg.exe show` خوانده می‌شوند (بدون درخواست خروجی dump شامل کلیدها). ترافیک جدید بین دو نمونه نمایش داده می‌شود؛ نبود ترافیک یا قدیمی‌بودن handshake به‌تنهایی به معنی قطعی نیست، چون peer ممکن است بی‌کار باشد. اگر این ابزار در دسترس نباشد وضعیت سرویس همچنان جداگانه نمایش داده می‌شود.

## پیش‌نیازها

- Windows 10 یا جدیدتر
- .NET 8 Desktop Runtime برای اجرای نسخهٔ ساخته‌شده
- [WireGuard for Windows](https://www.wireguard.com/install/) برای ایجاد و مدیریت سرویس‌های تونل
- برای ساخت از سورس: .NET 8 SDK

## ساخت

از ریشهٔ مخزن اجرا کنید:

```powershell
dotnet build .\StarlinkVpnManager\StarlinkVpnManager.csproj
```

برای اجرای برنامه:

```powershell
dotnet run --project .\StarlinkVpnManager\StarlinkVpnManager.csproj
```

## نکته

آزمایش هوشمند فقط پس از درخواست کاربر پنج بستهٔ ICMP به دروازهٔ محلی و هر یک از `1.1.1.1` و `8.8.8.8` می‌فرستد؛ برای پروفایل انتخاب‌شده، نام میزبان‌های Endpoint را هم با DNS سیستم resolve می‌کند. اگر VPN فعال باشد، مقصدهای عمومی از مسیر فعلی سیستم (احتمالاً تونل VPN) آزمایش می‌شوند. این بررسی ممکن است تحت تأثیر فیلترشدن ICMP باشد، اجرای سرویس را با handshake اشتباه نمی‌گیرد و هیچ تنظیمی از VPN، MTU یا روتر را خودکار تغییر نمی‌دهد.
